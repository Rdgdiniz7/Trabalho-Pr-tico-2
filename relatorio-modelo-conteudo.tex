\section{Problema}
O projeto desenvolve um sistema para apoiar o gerenciamento de uma locadora de veículos, com registro de fabricantes, categorias, clientes, veículos e aluguéis, além da devolução de veículos.
\section{Modelagem e tecnologias}
O back-end utiliza ASP.NET Core, Entity Framework Core e SQL Server. O front-end foi implementado com HTML, CSS, JavaScript e Bootstrap, fazendo requisições HTTP para a API. As entidades são relacionadas para permitir registrar o veículo e o cliente de cada aluguel.
\section{Artefatos e telas}
O front-end contém áreas de fabricantes, categorias, clientes, veículos e aluguéis, com operações de cadastro, atualização, remoção, listagem e filtros em dois campos. A tela de consultas executa os endpoints do FiltrosController para filtrar veículos por fabricante e categoria, aluguéis por CPF e período e veículos nunca alugados.
